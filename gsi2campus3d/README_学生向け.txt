Campus3D Workflow [A] — GSI2Campus3D v0.4.29
================================================

この ZIP は完全版です。既存 v0.4.25 のユーザー、旧版のユーザー、初回のユーザーが
同じ ZIP を使用できます。別の LocalExtent アドオンは不要です。

【インストール】
1. QGIS を起動します（授業の推奨環境: QGIS 3.44 LTR）。
2. 「プラグイン」→「プラグインの管理とインストール」→「ZIPからインストール」。
3. GSI2Campus3D_v0.4.29_Complete.zip を指定します。
4. 旧版がある場合、上書き・再インストール確認に従います。
5. 読み込み中の場合は、QGIS を再起動してください。
6. 「インストール済」で GSI2Campus3D v0.4.29 が有効になっていることを確認します。

【外部の前提条件】
GSIのDEM XMLから新規DEMを生成するときは QuickDEM4JP が必要です。
QGISのプラグイン管理で QuickDEM4JP を別途インストール・有効化してください。
Blender側の別プラグイン「Campus3D Tools / B」はこのZIPには含みません。
Blenderにインポートするには授業指定のBlender側ツールを別途導入してください。

【v0.4.29 変更点】
- 選択した矩形の内部を塗らず、青い四辺だけ表示するよう修正しました。
- 領域選択・Terrain格子間隔・出力・保存など他の機能は変更していません。

【v0.4.28から継続する機能】
- 「地図上で矩形を選択」のすぐ下に「地形メッシュ解像度・出力規模」を設置しました。
- 格子間隔の数値変更や矩形選択と同時に、頂点数・三角形数を更新します。
- 局所出力は25万頂点超で注意、100万頂点超で上限超過の警告を表示します。
- 上限超過の場合は必要な格子間隔の目安も自動表示します。
- 区画全体出力でも見積り・注意を即時表示します。

既存の3Dモデル用データを生成した後、[A-2] Blenderパッケージ出力で
「地図上で矩形を選択」をクリックし、2D地図上をドラッグします。
「任意矩形範囲だけをBlenderへ出力」がONであることを確認して、
「Terrain格子間隔（m）」を設定し、Blenderパッケージ出力を押します。
選択を解除（またはチェックOFF）すれば従来の区画全体出力に戻ります。

【留意事項】
- 元DEMの画素より細かいメッシュを指定しても標高データの精度は上がりません。
- 建物の切断端面は仮想面であり熱収支計算に直接用いないでください。
- 自作コードはQGIS 3.44での実機テスト未実施のため、授業配布前に教員PCで検証してください。
- 切り出しDEM / OBJ / 画像は選択範囲に合わせて出力します。
  ※ v0.4.29では任意矩形を出力すると、既存の出力を消さずに
     Campus3D_Blender_Local_2m_500x500m_001 のような専用フォルダを自動生成します。
     同じ条件で2回目に出力すると末尾が _002 になります。
     区画全体（任意範囲OFF）は従来の Campus3D_Blender を使用します。

【技術仕様】
- プラグインID: gsi2campus3d （旧版と同一）
- QGIS Python プラグインの標準ディレクトリ構成
- LocalExtentを本体に同梱し、外部アドオンへの参照なし
- 地形最大100万頂点、25万頂点超で警告（局所出力）
- 選択範囲はDEMの範囲内で指定。区画またぎは元DEMがカバーする場合に対応。
- 追加出力: campus3d_metadata.json


【v0.4.29: Blenderへの取り込み】
各出力フォルダ内にある campus3d_manifest.json を、Blenderの Campus3D Tools [B] で指定。
campus3d_metadata.json は範囲・格子・原点などの保存用記録で、通常は直接読み込みません。
"manifest" と同じフォルダ内にOBJ/PNGが置かれた状態を保持してください。
